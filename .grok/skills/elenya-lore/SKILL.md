# Lore — continuité

Lire `docs/ELENYA_BIBLE.md` et `docs/DESIGN_DECISIONS.md` si le détail manque. Voix : skill `elenya-frost-characters`.

Avant d’écrire une scène, répondre :

1. Qui est présent physiquement ?
2. Pourquoi, où, quand ?
3. Que sait chacun ? Que ne doit-il pas savoir encore ?
4. Que s’est-il passé juste avant ?
5. Quelle relation (lien, intérêt, présence, route) existe maintenant ?
6. Solo = indépendance, pas absence magique des compagnons.

Registres : Kaelen ombre / lame / silence / provocation. Alistair lumière / foi / retenue / culpabilité. Fen chaleur / repos, jamais compteur romantique. Elenya décide ; elle n’est pas un prix.

Ne pas recycler les métaphores porte, cage, chaîne, insigne, terme, destin si elles n’apportent rien. Ton vécu, pas annoncé.
